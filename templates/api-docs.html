Копирник API

Комнаты, буферы и файлы

Публичное API без ключей и регистрации. Базовый путь: /api/v1.

OpenAPI 3.1 · JSON

Код комнаты — строка из четырёх цифр, например "0042". Все операции выполняются в указанной комнате.

МетодПуть после /api/v1Действие

Создать комнату с текстом

POST /api/v1/rooms
Content-Type: application/json

{"title": "Заметки", "content": "Текст из чата"}

Ответ 201 содержит id комнаты, buffers, files и expires_at. В браузере комната доступна по /r/{id}.

Создать или изменить буфер

POST /api/v1/rooms/0042/buffers
Content-Type: application/json

{"title": "Запрос", "content": "SELECT 1;"}

PATCH /api/v1/rooms/0042/buffers/BUFFER_ID
Content-Type: application/json

{"content": "SELECT 2;"}

Для простого обновления передавайте название и/или текст. Можно добавить version из ответа: если другой участник уже изменил буфер, сервер вернёт 409 с актуальным буфером в поле note.

Загрузить файл

POST /api/v1/rooms/0042/buffers/BUFFER_ID/files
Content-Type: multipart/form-data

file: содержимое файла

В ответе поле file содержит id, buffer_id, исходное имя и download_url. По этой ссылке GET возвращает файл, DELETE удаляет его.

Срок жизни и ограничения

Два часа без изменений. Запись текста, операции с файлами и скачивание продлевают срок; чтение комнаты и списков — нет. Данные хранятся в памяти и удаляются при перезапуске сервера. При удалении последнего буфера появляется новый пустой.

До 30 буферов, 20 файлов, 25 МиБ на файл, 50 МиБ на комнату, 1 000 000 символов в буфере.

Ошибки возвращаются в JSON: {"error": "Описание"}. Коды: 400 — неверные данные или лимит количества, 404 — ресурс отсутствует, 409 — конфликт версии, 413 — превышен размер, 415 — неверный Content-Type, 503 — закончились коды комнат.
